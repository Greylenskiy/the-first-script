# The First Script

Мой первый скрипт на Python.

## Описание

Всем привет! Это мой маленький скрипт. Он создан на основе основ языка Python.
Он умеет определять, есть ли в вашем имени гласные буквы, считать сумму накоплений, а ещё в нём есть калькулятор.

## Требования

- Python 3.8+
- Git

## Запуск

```bash
python the_first_cript.py
```
